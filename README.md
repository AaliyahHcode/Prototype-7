Village Helper with Grid System

Objective:
Help villagers by collecting the resources they need and delivering them before helping the next villager.

Controls:
Arrow Keys - Move between hexagonal tiles.

Use the Arrow Keys to move. Press G near a Tree, Well, or Treasure Chest to collect a resource.
Find a villager and press D to deliver the requested item. 
Villagers request different resources and leave once their needs are met.
